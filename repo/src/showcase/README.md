# Dependency-Free Unity Showcase

Open `UnityProject` with Unity `6000.3.11f1`, open
`Assets/Scenes/Showcase.unity`, and press Play.

The instrument, participants, environment, and materials are editable before
Play. The project uses no third-party networking package or external media
asset. Its local two-participant runtime demonstrates the backend-independent
access and allocation behavior that production adapters transport over a
network.

Benchmark CSV files are written to `UnityProject/EvaluationExports` in the
Editor and to `EvaluationExports` beside the standalone executable in a build.
