# VLab Orchestrator Core

This package is the SDK-independent compilation surface of VLab Orchestrator.

It includes:

- The real FCFS queue and allocation policy
- User and shared-instrument state models
- Project configuration
- Benchmark protocol settings
- Tabbed backend package and SDK setup
- Red/green dependency status with one primary action
- Direct handoff to the project configuration asset
- The Unity research workspace

Open the workspace from:

`VLab Orchestrator > Setup`

Networking SDKs are optional and are not redistributed by this package.
The workspace provides a pinned one-click install for Unity Netcode and opens
the official setup flows for FishNet, Mirror, PUN 2, and Fusion.
