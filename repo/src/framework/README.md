# Framework Source Snapshot

This directory contains project-authored orchestration source from the current
V-Lab integration, excluding third-party SDK source and AI provider
implementations. Dormant AI configuration and telemetry hooks remain for source
provenance but are not used by the showcase or claimed for publication v1.

It is retained here for code inspection and publication extraction. Some files
still reference optional backend types and will be separated into SDK-specific
assemblies before the public release.

The dependency-free playable compilation surface is located in
`../showcase/UnityProject`.
