# SoftwareX Submission Documents

These files accompany the SoftwareX manuscript for VLab Orchestrator. They are
editable source copies; generate or upload Word documents where Editorial
Manager requests an editable file.

## Included

- `COVER_LETTER.md`: concise letter to the SoftwareX editor
- `HIGHLIGHTS.md`: five submission highlights, each below 85 characters
- `CREDIT_AUTHOR_STATEMENT.md`: proposed CRediT allocation
- `DECLARATION_OF_COMPETING_INTEREST.md`: manuscript declaration wording
- `DATA_AVAILABILITY.md`: archived-software and evidence statement

## Confirm Before Submission

- Corresponding author's email and postal address
- Final author order, affiliations, and ORCIDs
- Both authors' approval of the CRediT allocation
- Both authors' competing-interest declarations
- Funding statement and official grant identifiers, if any
- Whether Editorial Manager requires Elsevier's separate declaration form

The software and retained functional-validation evidence are archived at
https://doi.org/10.5281/zenodo.21756997.

Generate editable Word copies with:

```powershell
.\tools\publication\Build-SoftwareXSubmissionDocuments.ps1
```
