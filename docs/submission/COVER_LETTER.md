Dear Editor,

Please consider our manuscript, "VLab Orchestrator: A multi-backend
orchestration and controlled evaluation framework for Unity virtual
laboratories," for publication as an Original Software Publication in
SoftwareX.

VLab Orchestrator addresses the engineering and reproducibility problem created
when collaborative Unity applications couple their session, shared-access,
authority-transfer, synchronization, and evaluation logic directly to one
networking SDK. The software places a common application-level model above five
heterogeneous backends: Photon PUN 2, Photon Fusion, Unity Netcode for GameObjects,
FishNet, and Mirror. It also provides deterministic two-user scenarios,
validity-aware telemetry, a common export schema, and a rights-cleared showcase
that can be installed and evaluated independently of the original V-Lab project.

The accompanying evidence consists of one functional-validation run for each of
five scenarios on each backend, together with anomaly-validation runs, raw
exports, protocol definitions, and system metadata. We present these results as
evidence of protocol execution and inspectability, not as a statistically
replicated ranking of backend performance. The public source, documentation,
and retained evidence are available under the MIT License at
https://github.com/Nikolhs123/VLab-Orchestrator. The evaluated `v1.0.0` snapshot
is permanently archived at https://doi.org/10.5281/zenodo.21756997.

We believe the submission fits SoftwareX because its principal contribution is
reusable research software that makes a common collaborative workflow
inspectable across multiple networking implementations while documenting the
legal and technical boundary around third-party SDK installation.

The manuscript is original, is not under consideration elsewhere, and has been
approved by all authors.

Thank you for considering our manuscript.
