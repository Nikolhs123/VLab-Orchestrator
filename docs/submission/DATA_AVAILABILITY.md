# Data and Code Availability

The source code, installation documentation, benchmark protocol, raw
functional-validation exports, system-environment description, and
anomaly-validation evidence are available in the archived VLab Orchestrator
`v1.0.0` release at https://doi.org/10.5281/zenodo.21756997. The active public
repository is available at https://github.com/Nikolhs123/VLab-Orchestrator.

The archived evidence contains one principal Windows-to-Windows run for each of
five deterministic scenarios on each of five networking backends. These 25 runs
support functional validation and descriptive analysis. They are not a
statistically replicated dataset for inferential backend-performance ranking.
Third-party networking SDKs and service credentials are not redistributed;
evaluators obtain them from their official providers under the applicable
licenses and follow the repository's versioned installation instructions.
