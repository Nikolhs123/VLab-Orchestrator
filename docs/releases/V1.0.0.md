# VLab Orchestrator 1.0.0

VLab Orchestrator `1.0.0` is the first public-ready SoftwareX research-software
release. It provides one Unity orchestration, shared-access, synchronization,
telemetry, and deterministic evaluation layer across five multiplayer backends.

Archived release DOI: [10.5281/zenodo.21756997](https://doi.org/10.5281/zenodo.21756997)

## Included

- SDK-independent FCFS queue, policy, participant, and instrument state core
- Rights-cleared playable showcase built from Unity primitives
- Project-authored adapters for Photon PUN 2, Photon Fusion, Unity Netcode for
  GameObjects, FishNet, and Mirror
- Setup workspace with pinned SDK validation and safe uninstall/reinstall
- Generated shared instrument, avatar, queue, and backend runtime authoring
- Five canonical two-user benchmark scenarios
- Validity-aware telemetry and common CSV export schema
- Retained Windows-to-Windows candidate and anomaly-validation data
- Architecture, provenance, licensing, benchmark, and illustrated setup guides

## Audited Environment

- Unity `6000.3.11f1`
- Windows 11, x86-64 non-development standalone players
- Photon PUN 2 `2.55`
- Photon Fusion `2.0.9 build 1566`
- Unity Netcode for GameObjects `2.11.0`
- FishNet `4.6.22`
- Mirror `96.0.1`

Provider SDKs and Photon App IDs are intentionally excluded. Evaluators must
obtain SDKs through official provider channels, accept their licenses, and use
their own credentials. Follow the
[illustrated guide](../installation/ILLUSTRATED_GUIDE.md).

## Validation

The release has been exercised through clean-clone Unity import, complete SDK
matrix installation, SDK uninstall/reinstall, five-backend runtime validation,
Windows builds, two-client session lifecycle, synchronized shared-object
operation, canonical benchmark completion, and validity-aware export.

The retained dataset demonstrates protocol completion for the reported runs. It
does not, by itself, establish universal backend equivalence or statistically
rank backend performance. Such claims require balanced independent repetitions,
network-condition controls, and uncertainty analysis.
